# Tracker v2.3 — Direct COA management

- COA index is now a searchable-by-compound management table with View/Edit and Add COA.
- New COA creation from the COA page, linked to an initial vial.
- COA detail page supports editing metadata, replacing PDF/image attachments, viewing documents, linking and unlinking vials, and deleting COAs.
- Shared COA deletion unlinks all vials; unlink resets the vial’s use-COA-content flag.
- Existing upload validations, storage limits, and legacy schema handling retained.
- No database migration required.
