Peptide blends

Record transfers from multiple source vials (including multiple vials of the same peptide) into destination vial(s). This is an inventory and arithmetic record, not a preparation or dosing recommendation. A blended vial is tracked separately from single-compound vials.

Before recording: The what-if calculators do not change stock. The final Record action creates destination vial records and deducts transferred inventory. Check all actual transfer amounts first.

Reconstitution / 3 mL cartridge what-if

Each dry source vial is reconstituted first, before a measured portion is withdrawn for blending. Enter your target dose per peptide and desired blend draw volume. The planner maximizes the number of complete draws using available peptide content, per-vial capacity, and the maximum number of destination vials, automatically deriving each transfer amount. It calculates source-vial BAC volumes using an illustrative equal-withdrawal allocation; manual mode uses entered BAC values. Target dose ratios are maintained automatically.
