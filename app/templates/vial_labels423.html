Printer setup

In the print dialog choose actual size / 100%, zero margins and the full strip media size—not the individual sticker when several stickers share a strip. Print one test strip before producing a batch. If the browser driver changes page dimensions, import the exported PNG or SVG into compatible label software instead.

Rotation changes the text direction inside each sticker, not the strip dimensions. For 10 × 20 mm (four across), try 90° or 270° to read along the 20 mm edge. The SVG preview and PNG export use the same direction.
