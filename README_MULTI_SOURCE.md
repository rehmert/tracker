MULTIPLE SOURCE VIALS — TRACKER BLENDS

Supports 2–32 distinct source vial records, including multiple vials of the same compound.
For repeated compounds, enter the same TOTAL target dose per draw on each source row.
The maximum-draw planner pools available peptide content across those vials and allocates
transfers in selected source order. Source dilution remains a what-if assumption.

Recorded transfers retain a separate component per source vial. Component target amounts
are allocated proportionally, and recorded dose summaries aggregate by compound.

No database migration. Install on top of the multiple-destinations release.
Stop the service and back up /opt/tracker before applying.
