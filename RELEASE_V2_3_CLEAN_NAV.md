# Tracker v2.3 — Clean navigation toolbar

Moves Search Tracker from the left sidebar to a compact toolbar above page content. Moves Display density, Appearance and keyboard shortcut help into a right-aligned Preferences popover. Left navigation retains links and menu sorting controls. Preferences continue to persist in browser localStorage through existing density.js and theme.js. No schema changes.

The Preferences panel closes on outside click or Escape and remains keyboard accessible. On mobile, the toolbar sits below the mobile navigation bar.
