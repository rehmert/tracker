Tracker Eastern timestamp display patch

Apply on top of the working projected-dose-exclusion + minimal-Eastern-clock release.

Audit fields generated by SQLite CURRENT_TIMESTAMP / func.now() or explicit UTC
are displayed in America/New_York using the utc_dt filter.
User-entered naive event timestamps are interpreted as Eastern wall time using dt.
Aware datetimes, including backup file modification timestamps, convert to Eastern.
Date-only fields are unchanged. Data and schema are untouched.

Note: Historical rows populated by an alternative application clock rather than
SQLite UTC defaults cannot be reliably distinguished without provenance.

Installation:
  sudo systemctl stop tracker
  sudo tar -czf /root/tracker-before-display-$(date +%Y%m%d-%H%M%S).tar.gz -C /opt tracker
  sudo unzip -o tracker-eastern-display-patch.zip -d /opt/tracker
  sudo chown -R tracker:tracker /opt/tracker/app
  sudo systemctl start tracker
